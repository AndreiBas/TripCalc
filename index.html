❓ TripCalc Complete Guide

➕ Adding & Splitting Expenses

Enter the date, choose a category, and describe the activity. You can add searchable #tags (e.g. #dinner #tickets) in the tag input field.

  • Equal Split: Splitting equally among selected people. You can add + Extra $ (extras bought only by that person) or specify an Exact Share $ (overrides the equal split for them).
  • Percentage Split: Assign exact percentages (e.g. 60% and 40%) for the cost split. Must sum to 100%.

👥 Participants and settings

Add participant names. Click on their name badge to rename them or click the 👥 Edit Group button on their badge to assign them to families/groups (e.g. Smith Family).

Setup Memory: Use Save Setup Memory to store your active participant names and groups in local memory. Clicking Load Setup Memory recovers them instantly for a new trip.

💱 Multiple Currencies

Set a secondary currency (e.g., EUR, CZK, CAD) in the Cur: field in the header. The app automatically fetches the latest conversion rate against USD, which you can customize or manual refresh with the Fetch Latest Rate button. All inputs in that currency are converted to USD in the final standings.

☁️ Supabase Cloud Sync

Keep your trips safely synced in the cloud. Click Sync (or Connect Cloud) to enter your Supabase connection parameters (URL, Key, and a custom security PIN).

  • Your data is encrypted locally in your browser using AES-256 before being sent to the database. The database stores only ciphertext. No one can read your data without your security PIN.
  • Use S (Save) and L (Load) on slots 1, 2, or 3.
  • Toggle Auto-Sync to automatically push local updates to the cloud in real-time.

📂 File Export & Import

Save backups locally on your device:

  • Save: Exports a standard JSON file containing all trip data.
  • 🔐 Secure Save: Exports an encrypted JSON file protected by a password PIN. Can only be loaded if the user enters the correct PIN.
  • Load: Click to import standard or secure JSON backup files.

💸 Final Settlements

The app automatically calculates the net balance for each group or individual, listing who owes whom. It runs an optimization algorithm to resolve all debts in the absolute minimum number of payments.
