🚀 60-Second Quick Start

Imagine a weekend trip with Alice, Bob, and a couple John & Jane:

  1. Add Names: Type Alice, Bob, John, Jane under Participants.
  2. Form Groups: Click 👥 on John & Jane's badges, group them as Smith Family. Their individual balances will combine.
  3. Add Bill (Equal + Addons): Alice pays $100 for dinner. Under Equal Split, check Bob & Smith Family.
    • John ordered an extra drink for $10. In + Extra $ next to John's name, type 10. The app splits the rest equally.
  4. Check Standings: Look at the standings and settlement block. It instantly displays who owes whom.
  5. Export Report: Click 📄 Export HTML to save a beautiful, print-ready summary report.

➕ Expenses & Advanced Splits

Enter the date, choose a category, type a description, and input the amount. You can add searchable #tags (e.g. #taxi or #lunch) in the tag field.

  • Equal Split: Cost is shared evenly.
    • + Extra $ (Addon): Individual extras (e.g., John ordered steak, others had soup). It adds this amount to John's debt *before* splitting the remainder.
    • Exact Share $ (Override): Fixes the exact cost for this person, bypassing the equal share division entirely.
  • Percentage Split: Define custom splitting ratios (e.g., 60% / 40%). The sum of all selected percentages must equal 100%.

👥 Grouping & Setup Memory

Consolidate balances by grouping couples, roommates, or families:

  • Assign Group: Click the 👥 icon on any participant badge to add them to a custom group.
  • Rename Badges: Click directly on a participant's name badge to change their name instantly.
  • Setup Memory: Don't re-type names for every new trip! Click Save Setup Memory to save names and groups locally. Click Load Setup Memory to restore them instantly for a new sheet.

📜 Activity Ledger & Smart Filters

Navigate and isolate transactions in the ledger card:

  • Collapsible View: Click the arrow triangle `▼` to collapse the ledger list out of sight.
  • Sorting: Sort by Date, Amount, Description, or Category in ascending/descending order.
  • All-in-One Toggle: Tap the dynamic 🚫 All or ✅ All button next to the title to ignore or include all activities in calculations instantly.
  • Search & Exclude Tags: Type #tag to filter by that tag, or type -#tag to **exclude** activities containing that tag. Autocomplete suggestions dynamically list tags present in shown activities.
  • Bulk Edit Tags: Click the 🏷️ Multiple Edit button on any activity card to open a bulk tag editor modal. You can add or remove tags globally across all currently filtered, active activities at once.
  • Click-to-Filter Insights:
    • Click on a Category Icon (e.g. 🍔 Food) in the Category Breakdown table to view only Food activities.
    • Click on a Name in the Standings table to show only activities paid by or involving that person.
    • Click the **"All"** category filter item or refresh the page to clear filters.

💱 Multi-Currency Handling

Add expenses in foreign currencies seamlessly:

  • Secondary Currency: Type a code (e.g. EUR, CAD, JPY) in the Cur: header field.
  • Live Exchange Rates: Click the update button to query live rates from a currency exchange API. You can manually adjust this rate at any time.
  • Input Conversion: Expenses entered under the secondary currency display converted amounts in the ledger, calculated against your base currency.

📝 Smart Trip Notes

Write travel details, lists, and itineraries inside the Notes overlay editor:

  • 🔍 Live Search: Search text inside notes. Matching terms are highlighted.
  • 📖 Table of Contents: Format sections using Heading 2 (H2). A clickable Table of Contents dynamically displays in the search bar to jump to sections instantly.
  • 🎨 Auto-Color Highlight: When enabled, the editor auto-colors date strings, currency symbols, and numbers in the editor for quick scanning.
  • Reliable Auto-Save & Sync: Edits auto-save to browser storage every 15 seconds during typing, and trigger **instant local save and cloud sync** when closing the modal, locking your phone, or turning off the screen.

☁️ Cloud Sync & Backups

Ensure real-time sync across your PC, mobile, and web app:

  • Zero-Knowledge Encryption: All cloud backups are encrypted client-side using AES-256. The cloud database only stores ciphertext; it is impossible to read without your **Session PIN**.
  • Trip History (Restore Points): Enable this in Settings to automatically keep up to 3 encrypted restore points per trip slot, allowing you to easily undo mistakes.
  • Sync Slots: Save or load manual backups across 3 slots (S1/L1, S2/L2, S3/L3).
  • Auto-Sync: Real-time synchronization is triggered after any transaction edit or notes change.
  • Offline Reconciliation: If you edit offline, changes save locally. When your connection returns (e.g. WiFi turns on), the app detects the local edits and pushes them to the cloud automatically.
  • 📄 Export HTML: Downloads a print-ready standalone HTML report containing standings, category distributions, settlements, and nested group details.

📅 Floating Calendar

Open the draggable calendar by clicking 📅 next to the Activity Ledger header or inside the Trip Notes modal:

  • Month Navigation: Use the ◀ and ▶ buttons to change months.
  • Click to Paste: Clicking any day button instantly writes that date (e.g. 2026-07-08 or July 8, 2026) into the active form input or notes cursor location automatically.
  • Paste Today: Click the bottom button to quickly copy/paste today's current date.

⌨️ PC Calculator Shortcuts

When the calculator overlay is active on desktop screens, you can use your keyboard directly:

  • 0-9, +, -, *, /, ., %, (, ) to enter expressions.
  • Backspace to delete a digit.
  • Escape or Delete to clear.
  • Enter or = to calculate the result.
  • (Keyboard captures are ignored when typing inside text boxes or the notes editor).
